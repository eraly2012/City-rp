# City RP Mobile v0.7

Офлайн-прототип на Godot 4.x.

Новое в версии 0.6 — окно чата с командами:
- `/help` — список команд
- `/me текст` — действие персонажа
- `/do текст` — описание ситуации
- `/stats` — данные персонажа
- `/balance` — игровой баланс
- `/id` — локальный ID игрока (1)
- `/garage` — открыть гараж
- `/house` — открыть недвижимость
- `/car` — вывести первую машину из гаража
- `/lk` — открыть или закрыть транспорт (переключает замок)
- `/engine` — сесть в машину или выйти
- `/work` — получить игровую награду за работу

Обычный текст в поле чата выводится как локальное сообщение игрока.
Команды работают локально. Игроков по сети, серверного чата и настоящих ID пока нет.

Запуск: импортировать `project.godot` в Godot 4.x и нажать Play.
Это исходный проект, не APK. Для сборки Android нужны Android SDK, JDK и Export Templates.
